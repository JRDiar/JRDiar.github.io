🔍 El Diagnóstico: ¿Por qué compra en el techo?
El bot sufre de "Ceguera de Proximidad".

El Culpa de la Emoción (brain_trend_birth.py): Este módulo detecta el nacimiento de una tendencia. Cuando el precio cruza las EMAs y el ADX sube, grita "¡COMPRA!". El problema es que ignora la ubicación geográfica del precio en el Grid. Solo mira la fuerza, no el mapa.

El Fallo de Seguridad (brain_entry_validator.py): Aquí debería haber un "portero" que diga: "Espera, la señal es buena, pero tenemos una resistencia de hormigón a solo un 0.2% de distancia. No vale la pena el riesgo". Ese cálculo está desactivado, mal configurado o es demasiado permisivo.

El bot ve un "Pump", se activa, y ejecuta la orden justo cuando el precio toca la línea roja del Grid, que es donde el precio suele rebotar hacia abajo.

🛠️ La Solución: Implementar el "Filtro de Espacio Libre"
Tenemos que obligar al bot a medir la distancia hasta la siguiente línea del Grid antes de disparar. Si no hay suficiente espacio para tomar ganancias (Take Profit) antes de chocar, la operación debe cancelarse.

================================================================
Valida entrada según la fase detectada.
FIX APLICADO: "Filtro de Espacio Libre". Calcula distancia exacta a la

Filosofía de Joel:
"NO entrar en VP, HH, soportes/resistencias.

    def validate_entry(self, symbol, direction, phase_result, force_result, ladder_data):

        Valida si puede entrar según fase
        
        Args:
            symbol: Par a analizar
            direction: 'BULLISH' o 'BEARISH'

            force_result: Resultado del filtro de fuerza
            ladder_data: Datos de timeframes
        
        Returns:
            dict: {
                'can_enter': bool,
                'reason': str,
                'wait_for': str  # Si debe esperar, qué condición
            }
        """
        print(f"\n✅ VALIDADOR DE ENTRADA: {symbol}")
        print("-" * 50)
        
        action = phase_result['action']
        phase = phase_result['phase']
        
        print(f"   Fase: {phase}")
        print(f"   Acción sugerida: {action}")
        
        # === CASO 1: EXPLOSIÓN → Validar zonas ===
        if action == 'ENTER_NOW':
            return self._validate_explosion_entry(symbol, direction, force_result, ladder_data)
        
        # === CASO 2: CORRECCIÓN → Verificar rebote ===

            return self._check_rebound_confirmed(symbol, direction, ladder_data)
        
        # === CASO 3: RECHAZAR ===
        else:
            return {
                'can_enter': False,
                'reason': phase_result['reason'],
                'wait_for': None,
                'validation_type': 'PHASE_REJECT'

    def _validate_explosion_entry(self, symbol, direction, force_result, ladder_data):
        """
        Valida entrada en explosión (no en resistencia)
        
        Verifica:
        1. No está en zona de alto volumen (VAH/POC)
        2. Tiene espacio hasta próxima resistencia (FIX AGREGADO)
        3. No está en HH reciente
        """
        print("\n   🔍 Validando entrada en explosión...")
        
        data_15m = ladder_data.get('15m', {})
        current_price = data_15m.get('current_price', 0)
        
        if current_price == 0:
            return {'can_enter': False, 'reason': 'Precio actual 0', 'wait_for': 'Datos'}

        # === CONFIGURACIÓN DE SEGURIDAD (Hardcoded fallback si no está en config) ===
        # Distancia mínima requerida en % para entrar antes de una resistencia
        MIN_DIST_SAFETY = getattr(config, 'MIN_DIST_TO_RESISTANCE', 0.60) 
        
        # === OBTENER DATOS DE ZONAS ===
        vp_data = data_15m.get('volume_profile', {})
        zigzag_data = data_15m.get('zigzag', {})

        vah = vp_data.get('value_area_high', 0)
        val = vp_data.get('value_area_low', 0)
        poc = vp_data.get('poc_current', 0)
        
        # Pivotes ZigZag
        pivots = zigzag_data.get('pivots', [])
        pivot_types = zigzag_data.get('pivot_types', [])
        
        # === OBTENER DATOS DE GRID (Horizontal y Diagonal) ===
        grid_data = data_15m.get('grid', {})
        diagonal_data = grid_data.get('diagonal', {})

        resistencia_diagonal = diagonal_data.get('resistencia_diagonal', 0)
        diagonal_valid = diagonal_data.get('valid', False)

        # === RECOPILACIÓN DE OBSTÁCULOS (FIX CRÍTICO) ===
        # Creamos una lista unificada de todas las resistencias posibles por encima del precio
        posibles_resistencias = []
        posibles_soportes = [] # Para shorts

        # 1. Agregar Diagonales
        if diagonal_valid:
            if resistencia_diagonal > 0: posibles_resistencias.append(('Diagonal Res', resistencia_diagonal))
            if soporte_diagonal > 0: posibles_soportes.append(('Diagonal Sop', soporte_diagonal))

        # 2. Agregar Volume Profile
        if vah > 0: posibles_resistencias.append(('VAH', vah))
        if poc > 0: 
            posibles_resistencias.append(('POC', poc))
            posibles_soportes.append(('POC', poc))
        if val > 0: posibles_soportes.append(('VAL', val))

        # 3. Agregar Pivotes Recientes (HH para resistencia, LL para soporte)
        if pivots and pivot_types:
            for p_price, p_type in zip(pivots[-5:], pivot_types[-5:]): # Mirar últimos 5
                if p_type == 'HH': posibles_resistencias.append(('Prev HH', p_price))
                if p_type == 'LL': posibles_soportes.append(('Prev LL', p_price))

        # 4. Agregar Grid Levels (si existen en integrated)
        grid_master = ladder_data.get('grid_master', {})
        if grid_master:
            integrated = grid_master.get('integrated', {})
            if integrated.get('resistencia_principal'): 
                posibles_resistencias.append(('Grid Master Res', integrated['resistencia_principal']))
            if integrated.get('soporte_principal'): 
                posibles_soportes.append(('Grid Master Sop', integrated['soporte_principal']))

        
        # === ANÁLISIS DE ESPACIO LIBRE (FREE SPACE) ===
        warnings = []
        blocks = []

        if direction == 'BULLISH':
            # Filtrar resistencias que están ARRIBA del precio actual
            resistencias_reales = [
                (nombre, precio) for nombre, precio in posibles_resistencias 
                if precio > current_price
            ]
            
            if resistencias_reales:
                # Encontrar la más cercana
                nombre_mas_cercana, precio_mas_cercano = min(resistencias_reales, key=lambda x: x[1])
                
                # Calcular distancia
                distancia_pct = ((precio_mas_cercano - current_price) / current_price) * 100
                
                print(f"   📏 Distancia a resistencia ({nombre_mas_cercana}): {distancia_pct:.2f}%")
                
                # VALIDACIÓN CRÍTICA
                if distancia_pct < MIN_DIST_SAFETY:
                    msg = f"Espacio insuficiente ({distancia_pct:.2f}%) hasta {nombre_mas_cercana}"
                    print(f"   ⛔ BLOQUEO: {msg} < Mínimo {MIN_DIST_SAFETY}%")
                    blocks.append(msg)
                elif distancia_pct < (MIN_DIST_SAFETY * 2):
                    msg = f"Cerca de {nombre_mas_cercana} ({distancia_pct:.2f}%)"
                    warnings.append(msg)
                else:
                    print(f"   ✅ Espacio libre suficiente ({distancia_pct:.2f}%)")
            else:
                print("   ✅ Cielo despejado (No hay resistencias cercanas conocidas)")

        elif direction == 'BEARISH':
            # Filtrar soportes que están ABAJO del precio actual
            soportes_reales = [
                (nombre, precio) for nombre, precio in posibles_soportes 
                if precio < current_price
            ]
            
            if soportes_reales:
                # Encontrar el más cercano (el mayor precio que sea menor al actual)
                nombre_mas_cercano, precio_mas_cercano = max(soportes_reales, key=lambda x: x[1])
                
                # Calcular distancia
                distancia_pct = ((current_price - precio_mas_cercano) / current_price) * 100
                
                print(f"   📏 Distancia a soporte ({nombre_mas_cercano}): {distancia_pct:.2f}%")
                
                # VALIDACIÓN CRÍTICA
                if distancia_pct < MIN_DIST_SAFETY:
                    msg = f"Espacio insuficiente ({distancia_pct:.2f}%) hasta {nombre_mas_cercano}"
                    print(f"   ⛔ BLOQUEO: {msg} < Mínimo {MIN_DIST_SAFETY}%")
                    blocks.append(msg)
                elif distancia_pct < (MIN_DIST_SAFETY * 2):
                    msg = f"Cerca de {nombre_mas_cercano} ({distancia_pct:.2f}%)"
                    warnings.append(msg)
                else:
                    print(f"   ✅ Espacio libre suficiente ({distancia_pct:.2f}%)")

        # === EVALUAR RESULTADO FINAL ===
        
        if blocks:
            # BLOQUEO DURO: No hay espacio para operar
            return {
                'can_enter': False,
                'reason': f"⛔ ZONA SATURADA: {blocks[0]}",
                'wait_for': 'Romper resistencia o corregir',
                'validation_type': 'ZONE_BLOCK',
                'blocks': blocks
            }
        
        if warnings:
            # Si hay warnings pero no bloqueo, verificamos fuerza extrema para ignorar
            force_level = force_result.get('force_level', 'NORMAL')

                    'warnings': warnings

        return {
            'can_enter': True,
            'reason': '✅ Espacio Libre Confirmado',
            'wait_for': None,
            'validation_type': 'CLEAN_ENTRY'
        }
    
    def _check_rebound_confirmed(self, symbol, direction, ladder_data):
        """
        Verifica si el rebote está confirmado
        
        Condiciones para rebote confirmado:
        1. Piso formado (LL o soporte tocado)
        2. Precio empieza a subir (últimas 3 velas)
        3. Momentum vuelve verde
        4. ADX mantiene fuerza
        """

        data_15m = ladder_data.get('15m', {})
        momentum_data = data_15m.get('momentum', {})
        adx_data = data_15m.get('adx', {})
        zigzag_data = data_15m.get('zigzag', {})
        
        # Obtener frames
        storage = get_frame_storage(symbol, '15m')
        price_values = storage.get_trajectory('price', 5)
        
        # Datos
        mom_color = momentum_data.get('color_current', 'gray')
        adx_trend = adx_data.get('adx_trend', 'estable')
        pivot_types = zigzag_data.get('pivot_types', [])
        last_pivot = pivot_types[-1] if pivot_types else 'UNKNOWN'
        
        # === CONDICIONES PARA REBOTE ===
        
        conditions = {}
        
        # 1. Piso formado (LL, HL después de caída)
        if direction == 'BULLISH':
            conditions['1_piso_formado'] = last_pivot in ['LL', 'HL']
        else:
            conditions['1_techo_formado'] = last_pivot in ['HH', 'LH']
        
        # 2. Precio subiendo (últimas 3 velas)
        if len(price_values) >= 3:
            if direction == 'BULLISH':
                conditions['2_precio_subiendo'] = price_values[-1] > price_values[-3]
            else:
                conditions['2_precio_bajando'] = price_values[-1] < price_values[-3]
        else:
            conditions['2_precio_moviendo'] = False
        
        # 3. Momentum color correcto
        if direction == 'BULLISH':
            conditions['3_momentum_verde'] = mom_color in ['lime', 'green']

        # === EVALUAR CONDICIONES ===
        
        confirmed_count = sum(conditions.values())

        print(f"   Condiciones de rebote:")

            print(f"   - {cond}: {'✅' if value else '❌'}")
        
        print(f"\n   Confirmadas: {confirmed_count}/{total_conditions}")
        
        # Necesita al menos 3 de 4 condiciones
        if confirmed_count >= 3:
            print("   ✅ Rebote CONFIRMADO")
            return {
                'can_enter': True,
                'reason': f'Rebote confirmado ({confirmed_count}/{total_conditions} condiciones)',
                'wait_for': None,
                'validation_type': 'REBOUND_CONFIRMED',
                'conditions': conditions
            }
        else:
            missing = [k for k, v in conditions.items() if not v]
            print("   ⏸️ Rebote NO confirmado aún")
            return {
                'can_enter': False,
                'reason': f'Rebote NO confirmado ({confirmed_count}/{total_conditions})',
                'wait_for': f'Faltan: {", ".join(missing)}',
                'validation_type': 'REBOUND_PENDING',
                'conditions': conditions
            }

"""
brain_trend_birth.py - Detector de Tendencia Naciente vs Moribunda
==================================================================
El bot SOLO debe entrar en tendencias NACIENDO, no cuando están MURIENDO.

FASES:
- DORMANT: ADX < 20 (sin tendencia)
- BIRTH: ADX 20-25 subiendo (naciendo) ✅ ENTRAR
- MATURE: ADX 25-40 estable
- DECLINE: ADX > 35 cayendo (muriendo) ❌ NO ENTRAR
"""


def calculate_adx_lifecycle(adx_current, adx_history, lookback=5):
    """
    Clasifica en qué fase del ciclo de vida está el ADX
    
    Args:
        adx_current: Valor actual de ADX
        adx_history: Lista de valores históricos
        lookback: Velas para calcular velocidad
        
    Returns:
        dict: {
            'phase': 'DORMANT'|'BIRTH'|'MATURE'|'DECLINE'|'TRANSITION',
            'velocity': float (cambio por vela),
            'acceleration': float (cambio de velocidad)
        }
    """
    # FALLBACK: Si no hay historial suficiente, usar solo adx_current
    if len(adx_history) < 3:
        # Clasificación básica sin velocidad
        if adx_current < 20:
            phase = 'DORMANT'
        elif adx_current > 40:
            phase = 'DECLINE'  # ADX muy alto = probablemente muriendo
        elif adx_current >= 25:
            phase = 'MATURE'
        else:
            phase = 'TRANSITION'
        return {'phase': phase, 'velocity': 0, 'acceleration': 0}
    
    # Calcular velocidad con la historia disponible
    actual_lookback = min(lookback, len(adx_history) - 1)
    if actual_lookback < 2:
        actual_lookback = 2
    
    recent = adx_history[-actual_lookback:]
    velocity = (recent[-1] - recent[0]) / actual_lookback
    
    # Calcular aceleración si hay suficiente historial
    if len(adx_history) >= actual_lookback * 2:
        prev_velocity = (adx_history[-actual_lookback] - adx_history[-actual_lookback*2]) / actual_lookback
        acceleration = velocity - prev_velocity
    else:
        acceleration = 0
    
    # Clasificar fase basándose en ADX actual + velocidad
    if adx_current < 20:
        phase = 'DORMANT'  # Sin tendencia
    elif adx_current < 25 and velocity > 1.0:
        phase = 'BIRTH'    # Tendencia NACIENDO ✅
    elif 25 <= adx_current <= 40 and abs(velocity) < 1.5:
        phase = 'MATURE'   # Tendencia MADURA
    elif adx_current > 35 and velocity < -0.3:
        phase = 'DECLINE'  # Tendencia MURIENDO ❌
    elif adx_current > 40:
        phase = 'DECLINE'  # ADX muy alto = probablemente agotándose
    else:
        phase = 'TRANSITION'
    
    return {
        'phase': phase,
        'velocity': round(velocity, 2),
        'acceleration': round(acceleration, 2)
    }


def detect_di_divergence(di_plus_current, di_minus_current, 
                         di_plus_prev, di_minus_prev):
    """
    Detecta si DI+ y DI- están divergiendo o convergiendo
    
    DIVERGING = Fuerza creciendo (separándose)
    CONVERGING = Fuerza muriendo (acercándose)
    
    Returns:
        str: 'DIVERGING'|'CONVERGING'|'STABLE'
    """
    spread_current = di_plus_current - di_minus_current
    spread_prev = di_plus_prev - di_minus_prev
    spread_change = abs(spread_current) - abs(spread_prev)
    
    if spread_change > 2:
        return 'DIVERGING'   # DI se separan → Fuerza creciendo
    elif spread_change < -2:
        return 'CONVERGING'  # DI se acercan → Fuerza muriendo
    else:
        return 'STABLE'


def detect_trend_phase(adx_data, momentum_data):
    """
    Clasifica la tendencia en EARLY/MID/LATE phase
    
    Args:
        adx_data: Dict de calculate_adx_with_memory
        momentum_data: Dict de calculate_momentum_with_memory
        
    Returns:
        dict: {
            'phase': 'EARLY'|'MID'|'LATE'|'DORMANT',
            'entry_allowed': bool,
            'bonus_penalty': int,
            'reasons': []
        }
    """
    # Calcular ciclo de vida del ADX
    lifecycle = calculate_adx_lifecycle(
        adx_data.get('adx_current', 0),
        adx_data.get('adx_history', [])
    )
    
    # Detectar divergencia DI
    di_divergence = detect_di_divergence(
        adx_data.get('di_plus_current', 0),
        adx_data.get('di_minus_current', 0),
        adx_data.get('di_plus_prev', adx_data.get('di_plus_current', 0)),
        adx_data.get('di_minus_prev', adx_data.get('di_minus_current', 0))
    )
    
    # Momentum fuerte
    mom_strong = momentum_data.get('consecutive_count', 0) >= 3
    
    phase = 'MID'
    entry_allowed = True
    bonus_penalty = 0
    reasons = []
    
    # ===== FASE EARLY (ENTRAR) =====
    if lifecycle['phase'] == 'BIRTH':
        if di_divergence == 'DIVERGING' and mom_strong:
            phase = 'EARLY'
            entry_allowed = True
            bonus_penalty = +30
            reasons.append("ADX naciendo desde bajo")
            reasons.append("DI+ separándose de DI-")
            reasons.append("Momentum acelerando")
        elif di_divergence == 'DIVERGING':
            phase = 'EARLY'
            bonus_penalty = +20
            reasons.append("ADX naciendo")
        else:
            phase = 'EARLY'
            bonus_penalty = +10
            reasons.append("Tendencia iniciando")
    
    # ===== FASE MID (EVALUAR) =====
    elif lifecycle['phase'] == 'MATURE':
        phase = 'MID'
        entry_allowed = True
        bonus_penalty = 0
        
        if di_divergence == 'CONVERGING':
            bonus_penalty = -15
            reasons.append("Cuidado: DI convergiendo")
    
    # ===== FASE LATE (NO ENTRAR) =====
    elif lifecycle['phase'] == 'DECLINE':
        phase = 'LATE'
        entry_allowed = False
        bonus_penalty = -60  # PENALTY SEVERA
        reasons.append("ADX cayendo desde pico")
        reasons.append("Tendencia MURIENDO")
        
        if di_divergence == 'CONVERGING':
            bonus_penalty = -80
            reasons.append("DI+ y DI- convergiendo")
    
    # ===== FASE DORMANT (SIN TENDENCIA) =====
    elif lifecycle['phase'] == 'DORMANT':
        phase = 'DORMANT'
        entry_allowed = False
        bonus_penalty = -40
        reasons.append("Sin tendencia (ADX < 20)")
    
    return {
        'phase': phase,
        'entry_allowed': entry_allowed,
        'bonus_penalty': bonus_penalty,
        'reasons': reasons,
        'lifecycle': lifecycle,
        'di_divergence': di_divergence
    }
