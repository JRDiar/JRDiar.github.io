El MovieEngine analiza la "película" del mercado viendo trayectorias de indicadores en múltiples timeframes.

Flujo:
1. _analyze_scene(symbol, '5m')  → Escena de acción inmediata
2. _analyze_scene(symbol, '1h')  → Contexto 48h
3. _analyze_scene(symbol, '4h')  → Estructura macro
4. integrate_scenes()            → Une cortometrajes
5. make_decision()               → Director decide
6. calculate_threshold()         → Threshold dinámico

- adx_trajectory: valores históricos de ADX

def _analyze_scene(self, symbol, timeframe, description):
    storage = get_frame_storage(symbol, timeframe)
    
    # Obtener trayectorias de últimos 5 frames
    adx_values = storage.get_trajectory('adx.value', 5)
    mom_values = storage.get_trajectory('momentum.age', 5)
    spread_values = storage.get_trajectory('adx.spread', 5)
    
    # Analizar movimiento
    adx_traj = self.analyzer.analyze_adx_motion(adx_values)
    mom_traj = self.analyzer.analyze_momentum_motion(mom_values)
    spread_traj = self.analyzer.analyze_spread_motion(spread_values)
    
    # Interpretar escena
    quality, story = self._interpret_scene(adx_traj, mom_traj, spread_traj)

Métodos para trayectorias/aceleración:
def get_trajectory(self, indicator_path, n=5):
    """
    Obtiene trayectoria de un indicador (la "animación")
    
    Example:
        trajectory = storage.get_trajectory('adx.value', 5)
        # [45, 48, 52, 56, 58] → subiendo
    """
    values = []
    frames = self.get_frames(n)
    for frame in frames:
        # Navegar ruta anidada ej: 'adx.value'
        value = frame
        for key in indicator_path.split('.'):
            value = value.get(key, 0)
        values.append(value)
    return values
