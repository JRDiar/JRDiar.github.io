Error identificado. El problema es que current_price llega como 0 en algunos casos (probablemente cuando no hay datos suficientes o error de lectura), y al dividir por él, explota.

1. CÓDIGO CON BUG (Actual)
python
    if profile_high > 0:
        # Calcular distancia en %
        # ERROR: Si current_price es 0, esto explota
        dist_to_high = ((profile_high - current_price) / current_price) * 100
2. CÓDIGO PROPUESTO (Fix)
Agregamos validación de current_price > 0.

python
    # Validar que tengamos precio y profile_high válidos
    if profile_high > 0 and current_price > 0:
        # Calcular distancia en %
        dist_to_high = ((profile_high - current_price) / current_price) * 100
        
        # Solo bloqueamos si estamos DENTRO del perfil (dist > 0) y MUY CERCA del techo (< 2%)
        if 0 < dist_to_high < 2.0:
            cond_vp_safe = False
            vp_block_reason = f"Price too close to VP High ({dist_to_high:.1f}% < 2%)"
