1. OPTIMAL TIMING (Timing Inteligente)
Ubicación: brain_intelligent.py línea 252 (después de zone awareness)
Archivos modificados: brain_config.py + brain_intelligent.py
4 Flags implementados:
pythonENABLE_PULLBACK_CHECK = True    # Penaliza overextended
ENABLE_BREAKOUT_CHECK = True    # Penaliza resistencia cerca  
ENABLE_HH_PENALTY = True        # Penaliza buying top
ENABLE_CLEAN_SPACE_BONUS = True # Premia espacio limpio
Lógica:
A) PULLBACK_CHECK: Si extension_ratio > 3.0 ATR Y distancia_al_POC > 2% → penalty -40

Detecta precio muy estirado lejos del Volume Profile POC
Indica necesidad de esperar retroceso

B) BREAKOUT_CHECK: Si resistencia < 1.0% arriba → penalty -30

Detecta techo inmediato
Indica necesidad de esperar confirmación de ruptura

C) HH_PENALTY: Si precio está cerca del máximo más alto (HH del ZigZag):

< 0.2% del HH → penalty -40 (peligro extremo)
< 0.5% del HH → penalty -20 (peligro)

D) CLEAN_SPACE_BONUS: Si resistencia > 3% Y HH > 3% → bonus +10

Premia setups con espacio limpio para desarrollarse

Penalties acumulativos: Si activan múltiples checks, se SUMAN (-40 -30 -20 = -90 total). Setup con múltiples problemas = rechazo automático.
Protección: score = max(0, min(100, score)) previene scores negativos.

2. TRADING_MODE (Perfiles de Agresividad)
Ubicación: brain_config.py línea 149
Variable: TRADING_MODE = 'CONSERVATIVE' (opciones: CONSERVATIVE, BALANCED, AGGRESSIVE)
Multiplicador de penalties:

CONSERVATIVE: penalties x1.0 (sin cambios)
BALANCED: penalties x0.8 (reduce 20%)
AGGRESSIVE: penalties x0.6 (reduce 40%)

Implementación en brain_intelligent.py:
pythonpenalty_multiplier = 0.6 if TRADING_MODE == 'AGGRESSIVE' else 0.8 if BALANCED else 1.0
