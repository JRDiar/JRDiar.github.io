2. ARCHIVOS A MODIFICAR
brain_intelligent.py
Integración: Se insertará el matcher justo después del análisis del Grid y antes de la auditoría final.
Lógica Override: Si el matcher encuentra una similitud > 85%, se forzará el status a OPERABLE incluso si el Grid lo bloqueó (útil para setups de alta fuerza que rompen reglas estándar).
3. ESTRUCTURA DEL MÓDULO (brain_pattern_matcher.py)
Clase PatternMatcher
init
: Inicializa y carga la librería de ADNs desde strategies/dna/.
load_dna_library(): Recorre la carpeta strategies/dna/*.json y carga los patrones en memoria. Muestra cuántos patrones válidos se cargaron.
compare_setup(current_setup, dna_setup): El núcleo matemático.
Compara métricas clave (ADX, Momentum, Swing) para cada timeframe (1H, 15M, 5M).
Retorna un % de similitud (0-100).
find_best_match(symbol, current_setup):
Itera sobre todos los ADNs cargados.
Retorna el mejor match con su score y nombre de archivo.
4. LÓGICA DE SIMILITUD (Weighted Time Ladder)
Se utilizará un sistema de pesos para dar prioridad al timeframe principal (15M).

Factor	Peso	Tolerancia de Match
15M (Principal)	50%	ADX ±5, Mom Color exacto, Swing ±30%
5M (Ejecución)	30%	ADX ±5, Mom Color exacto, Ancho Grid ±20%
1H (Contexto)	20%	ADX ±5, Mom Color exacto
Cálculo de Score:

Se calcula un sub-score (0-100) para cada timeframe basado en cuántos parámetros coinciden.
Score Final = (Score_15m * 0.5) + (Score_5m * 0.3) + (Score_1h * 0.2)
