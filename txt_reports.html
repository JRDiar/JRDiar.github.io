## 🔧 3. PENALIZACIÓN DINÁMICA DE CONTRADICCIÓN (brain_analyzer.py)

**Problema:** Si 4H es ALCISTA pero 1H es BAJISTA, se aplica una penalización fija de `-30`, matando el trade incluso si 1H es solo un pullback débil (ADX bajo).

### 🔴 Código Actual (Castigo Fijo)
**Ubicación:** `analyze_coin_complete` (Líneas ~625)
```python
if direction_4h == 'BULLISH' and direction_1h == 'BEARISH':
    contradiction_penalty = 30  # ← MUY ALTO
```

### 🟢 Código Propuesto (Inteligente)
Evaluar la fuerza (ADX) del timeframe contradictorio.
```python
# Diferenciar pullback (ADX 1H bajo) vs reversión (ADX 1H alto)
adx_1h_val = analysis_1h.get('adx', {}).get('adx_current', 0)

if direction_4h == 'BULLISH' and direction_1h == 'BEARISH':
    if adx_1h_val > 30:
        # Reversión fuerte: Castigo total
        contradiction_penalty = 30
    elif adx_1h_val > 20:
        # Pullback moderado: Castigo medio
        contradiction_penalty = 15
    else:
        # Corrección débil (normal): Castigo leve
        contradiction_penalty = 5
        
# APLICAR LÓGICA SIMÉTRICA PARA EL CASO INVERSO (BEARISH vs BULLISH)
elif direction_4h == 'BEARISH' and direction_1h == 'BULLISH':
    if adx_1h_val > 30:
        contradiction_penalty = 30
    elif adx_1h_val > 20:
        contradiction_penalty = 15
    else:
        contradiction_penalty = 5
```
