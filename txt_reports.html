BRAIN GRID - SISTEMA DE NAVEGACIÓN ESPACIAL (v6.0)

2. Calcular el "Puntero" (Vector de Fuerza Inmediata).
3. Determinar si el vehículo (precio) está atrapado, viajando o rebotando.

Filosofía:
- No operar en "Cajas Cerradas" (Grid Compression).
- Solo operar cuando el Puntero rompe la Malla con Fuerza.

import numpy as np
from brain_config import (
    GRID_LOOKBACK, GRID_COMPRESSION_TH, 
    GRID_POINTER_SENSITIVITY, GRID_EXPANSION_TH

class MarketGridNavigator:
    def __init__(self):
        self.last_status = {}

    def navigate(self, symbol, df_5m, df_15m=None):
        """
        Función Principal: Escanea la Malla y devuelve el Estado de Navegación.
        """
        if df_5m is None or df_5m.empty:
            return {'status': 'UNKNOWN', 'reason': 'No data'}

        grid = self._build_grid_structure(df_5m)

            'reason': reason,
            'grid_data': grid,
            'pointer_data': pointer,
            'confidence': confidence
        }

    def _build_grid_structure(self, df):
        """
        Dibuja las paredes de la malla (Donchian Channel Dinámico)
        """
        lookback = GRID_LOOKBACK
        highs = df['high'].rolling(lookback).max()
        lows = df['low'].rolling(lookback).min()
        
        current_ceil = highs.iloc[-1]
        current_floor = lows.iloc[-1]
        mid_line = (current_ceil + current_floor) / 2
        
        # Calcular densidad (Ancho de la malla en %)
        width_pct = ((current_ceil - current_floor) / mid_line) * 100
        
        # Determinar dirección de la malla (Slope de la linea media)
        # Usamos regresión simple de los últimos 5 puntos de la mid_line
        prev_mid = (df['high'].rolling(lookback).max().iloc[-5] + df['low'].rolling(lookback).min().iloc[-5]) / 2
        slope = mid_line - prev_mid
        
        trend = "FLAT"
        if slope > (current_floor * 0.0005): trend = "UP_TREND"
        elif slope < -(current_floor * 0.0005): trend = "DOWN_TREND"
        
        return {
            'ceiling': current_ceil,
            'floor': current_floor,
            'mid': mid_line,
            'density': width_pct,
            'trend': trend,
            'slope': slope
        }

    def _calculate_force_vector(self, df):
        """
        Calcula el Puntero (Vector Inmediato).
        Equivale a tu ejemplo: 98:205 -> 98:290.
        Usa Velocity y Micro-Momentum.
        """
        sensitivity = GRID_POINTER_SENSITIVITY
        closes = df['close']
        
        # Vector de Precio (¿A dónde fuimos en las últimas 3 velas?)
        price_delta = closes.iloc[-1] - closes.iloc[-sensitivity]
        velocity = price_delta / sensitivity
        
        # Vector de Volumen (¿Hay gasolina?)
        vol_now = df['volume'].iloc[-1]
        vol_avg = df['volume'].rolling(20).mean().iloc[-1]
        fuel = vol_now / vol_avg if vol_avg > 0 else 0
        
        direction = "NEUTRAL"
        if velocity > 0: direction = "UP"
        elif velocity < 0: direction = "DOWN"
        
        # Fuerza del vector
        strength = abs(price_delta) / closes.iloc[-1] * 100 # % de cambio
        
        return {
            'direction': direction,
            'velocity': velocity,
            'fuel': fuel,
            'strength': strength
        }

Resultado: grid_decision = "BLOCK". Razón: "Malla Cerrada". El bot ni siquiera intenta calcular el resto.

Caso ARCSOL (Rebote en Bajada):

Antes: Tendencia bajista, pero precio subiendo un poco. Bot entra Short porque es bajista, pero se come el rebote.

Ahora: brain_grid ve Tendencia Bajista (grid['trend'] == 'DOWN') PERO ve el Puntero subiendo (pointer['direction'] == 'UP').

Resultado: grid_decision = "WAIT_PULLBACK". Razón: "Malla baja pero Puntero sube". El bot espera a que el puntero se ponga rojo otra vez.
