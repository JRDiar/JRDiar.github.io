He analizado la fuga de Stablecoins y aquí está el reporte:

🚨 Diagnóstico del Problema: El filtro actual en bot_main.py es una Lista Negra Estática (Hardcoded). Esto tiene dos fallos graves:

Fuga Confirmada (1/USDT): El símbolo 1/USDT:USDT (que aparece en el exchange) NO está en la lista negra, por lo que el bot lo trata como una moneda normal y opera.
Fuga de USDC (Anomalía): USDC/USDT:USDT SÍ está en la lista negra actual. Si el bot lo está operando, es posible que:
El bot esté ejecutando una versión anterior del código en memoria.
O el exchange esté devolviendo el símbolo con algún caracter invisible/diferente que no coincide exactamente con el string de la lista.
❌ Por qué falla el diseño actual: Depender de una lista manual (['USDC/USDT:USDT', ...]) es ineficiente porque siempre aparecerán nuevos pares (como FDUSD, USDE, etc.) o variantes que no están en la lista.

💡 Solución Recomendada (Sin tocar nada aún): Cambiar la lógica de "Lista Exacta" a un "Filtro Dinámico Inteligente". En lugar de if symbol in LISTA, usar lógica que detecte patrones:

Si el símbolo contiene "USDC", "USDT", "DAI", "USD", "EUR" en la parte base (izquierda del par).
Ejemplo: if any(stable in symbol.split('/')[0] for stable in ['USDC', 'USDT', 'DAI', 'FDUSD', 'TUSD', 'USDE'])

🔴 Código Actual (El Problema)
En bot_main.py, dependemos de una lista exacta. Si el exchange cambia el nombre o aparece una nueva moneda, el filtro falla.

python
# Definición estática (Líneas 63-70)
STABLECOINS_BLACKLIST = [
    'USDC/USDT:USDT', 
    'USDT/USDT:USDT',
    'DAI/USDT:USDT',
    'BUSD/USDT:USDT',
    'TUSD/USDT:USDT',
    'FDUSD/USDT:USDT'
]

# ... Lógica de filtrado (Línea 158)

    print(f"⏭️ {symbol}: STABLECOIN - OMITIDO")
    continue
Por qué falló con 1/USDT: Simplemente no estaba en la lista. Por qué falló con USDC: Probablemente una discrepancia menor en el string o un espacio invisible.

🟢 Propuesta de Implementación (La Solución)
Usaremos un enfoque híbrido: Filtro Dinámico por Base (para atrapar todas las variantes de USD) + Blacklist Manual (para monedas específicas como '1').

python
# ============================================================================
# FILTROS DE MONEDAS
# ============================================================================

# 1. Bases de Stablecoins (Detecta USDC, TUSD, etc. en cualquier par)
STABLE_BASES = {
    'USDC', 'USDT', 'DAI', 'BUSD', 'TUSD', 'FDUSD', 'USDE', 'USDP', 'EUR', 'PAXG', 'USTC'
}

# 2. Blacklist Manual (Para tokens específicos que quieras bloquear, ej: "1")
MANUAL_BLACKLIST = {
    '1/USDT:USDT',
    'JASMY/USDT:USDT' # Ejemplo
}

# ... Dentro del loop de análisis ...

# Lógica Mejorada
base_currency = symbol.split('/')[0]  # Extrae "BTC" de "BTC/USDT:USDT"

is_stable = base_currency in STABLE_BASES
is_blacklisted = symbol in MANUAL_BLACKLIST

if is_stable or is_blacklisted:
    reason = "STABLECOIN" if is_stable else "BLACKLIST MANUAL"
    print(f"⏭️ {symbol}: {reason} DETECTADO - OMITIDO")
    continue
Ventajas:

Futuro-proof: Si mañana sale USDC/ETH, el filtro lo atrapa igual porque la base es USDC.
Flexible: Puedes agregar cualquier moneda "basura" a la MANUAL_BLACKLIST sin mezclarla con las stables.
