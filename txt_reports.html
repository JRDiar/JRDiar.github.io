5. Sistema de Entrada: Stop Loss ATR
Cálculo (calculate_stop_loss_atr() en bot_main.py)

# 1. Descarga 100 velas de 15M
# 2. Calcula ATR(14) con función calculate_atr() de indicators.py
# 3. Stop Loss = Entry ± (ATR × 1.8)
#    - BULLISH: stop = entry - (ATR × 1.8)
#    - BEARISH: stop = entry + (ATR × 1.8)
# 4. Límite máximo: 5% de riesgo
#    Si riesgo > 5% → ajusta stop a 5%

Ejemplo Práctico

Entry: $1.50000
ATR(14): $0.03000
Stop: $1.50000 - ($0.03000 × 1.8) = $1.44600
Riesgo: 3.6% ✅ (aceptable)

Si ATR fuera $0.05000:
Stop inicial: $1.50000 - ($0.05000 × 1.8) = $1.41000
Riesgo: 6.0% ❌ (excede límite)
Stop ajustado: $1.50000 × (1 - 0.05) = $1.42500
Riesgo final: 5.0% ✅

ADX Manual (Average Directional Index)

# Cálculo exacto según TradingView:
1. True Range = max(high-low, |high-prev_close|, |low-prev_close|)
2. DM+ = high - prev_high (si > DM- y > 0)
3. DM- = prev_low - low (si > DM+ y > 0)
4. Smoothed TR, DM+, DM- (Wilder smoothing, period=14)
5. DI+ = (Smoothed DM+ / Smoothed TR) × 100
6. DI- = (Smoothed DM- / Smoothed TR) × 100
7. DX = |DI+ - DI-| / (DI+ + DI-) × 100
8. ADX = SMA(DX, 14)

# Interpretación:
ADX >30: Tendencia fuerte
ADX 20-30: Tendencia moderada
ADX <20: Lateral/débil

ATR (Average True Range)

# Usado para stop loss:
ATR(14) = SMA(True Range, 14)
# Mide volatilidad promedio de 14 velas

Flujo Completo de Ejecución
Ciclo de Búsqueda (60s)

1. Pre-filtro velas semanales: 850 → 650 símbolos
2. Cascada 4H → 1H → 30M → 15M → 5M
3. Brain evalúa cada señal 5M:
   - Calcula score 0-100
   - Verifica estructura de precio
   - Analiza tendencias 4H/1D
   - Detecta EMAs extendidas
4. Si score ≥50 y hay cupos disponibles:
   - Calcula stop loss ATR
   - Entra en trade
   - Cambia a modo TRADING (30s)

Ciclo de Trading (30s)
1. Fetch precio actual de trades activos
2. Monitor con jerarquía:
   a) Stop Loss ATR → cierre inmediato
   b) ADX declinando 5v → cierre técnico
   c) Momentum revirtiendo → cierre técnico
   d) 90 minutos → time stop
3. Registra cada lectura en MONITOREO_MINUTO
4. Al cerrar:
   - Escribe TRADE_COMPLETO
   - Inicia monitoreo post-cierre (5 min)
   - Genera heurísticas automáticas
