# Análisis Detallado de Arquitectura - BrainTrader v5.0 (Sniper Real-Time)

Este documento detalla la estructura, lógica y funcionamiento del sistema actual `BrainTrader v5.0`, diseñado para facilitar su migración y evolución hacia una versión más avanzada.

## 1. Estructura General y Flujo de Ejecución

El sistema opera bajo un modelo de **Orquestación Centralizada con Ejecución Distribuida**, enfocado en el análisis continuo ("Sniper Mode").

### Módulos Principales
*   **`bot_main.py`**: Punto de entrada. Inicializa la conexión, el logging y el bucle principal. Ejecuta el ciclo `RealtimeSniper`.
*   **`brain_sniper_realtime.py` (The Sniper)**:
    *   Gestiona el escaneo continuo de monedas en lotes (`batches`).
    *   Mantiene dos colas:
        *   **Priority Queue**: Monedas con setups listos o casi listos ("Perfect Setup").
        *   **Waiting List**: Monedas con *Fuerza* detectada pero esperando confirmación técnica.
    *   Tiene autoridad para "promover" o "degradar" monedas dinámicamente.
*   **`brain_intelligent.py` (The Orchestrator)**:
    *   Coordina el flujo de análisis cognitivo.
    *   Ejecuta fases secuenciales: Percepción -> Detección Lateral -> Validación Matemática -> Memoria -> Visión Unificada.
*   **`brain_vision_unified.py` (The Decision Maker)**:
    *   Cerebro final que toma la decisión de entrada.
    *   Evalúa "trayectorias" (evolución de datos) en lugar de valores estáticos.
    *   Emite un veredicto de confianza (0-100%).
*   **`brain_analyzer.py` (The Analyst)**:
    *   Calcula indicadores técnicos y estructura para cada timeframe (4H, 1H, 15M, 5M).
    *   Implementa el sistema "Time Ladder" (penalizaciones graduales en lugar de bloqueos binarios).
*   **`brain_pattern_intelligence.py` (The Charter)**:
    *   Detecta patrones geométricos y estructurales (Triángulos, Flags, Doble Techos, HH/HL).

---

## 2. Lógica de Trading y Filtros

El sistema utiliza una filosofía de **"Física de Mercado + Estructura"**. No se basa en una sola señal, sino en la convergencia de múltiples factores.

### A. Filtros e Indicadores Clave
| Indicador | Configuración | Función |
| :--- | :--- | :--- |
| **ADX** | Periodo 14 | Mide la fuerza de la tendencia. Valor > 25 (ideal > 30) se busca para "Market Force". |
| **DI+/DI-** | Periodo 14 | Determina la dirección. `Spread` (diferencia) > 5.0 es requerido para evitar lateralización. |
| **Momentum** | LazyBear Type | Barras verdes/rojas. Buscan alineación de color y conteo consecutivo (>= 3 barras). |
| **ZigZag** | Custom/TTI | Detecta pivotes (HH, HL, LH, LL) para confirmar estructura de mercado. |
| **Exhaustion** | Custom | Mide qué tan extendido está el precio respecto a EMAs y si hay espacio para correr. |
| **Grid Diagonal** | Custom | Mide la posición del precio dentro de un canal dinámico (0-100%). Evita comprar en techo (>80%) o vender en piso (<20%). |

### B. Sistema "Time Ladder" (Escalera de Tiempo)
En lugar de decir "SI ADX < 25 -> BLOQUEAR", el sistema aplica **penalizaciones**:
*   *ADX bajo*: -10 a -20 puntos de score.
*   *Lateralización*: -30 puntos.
*   *Contradicción de Momentum*: -20 puntos.
*   *Espacio estrecho (Room)*: -15 puntos.

Esto permite que un setup "imperfecto" pero con mucha fuerza en otros aspectos pueda ser operado.

### C. Visión Unificada (Unified Vision)
Evalúa la "película" de los datos (trayectoria):
1.  **ADX Delta**: ¿Está subiendo la fuerza?
2.  **Candle Ratio**: ¿Están creciendo las velas a favor?
3.  **Momentum Age**: ¿Es un movimiento joven (nacimiento) o viejo (agotamiento)?
4.  **Exhaustion Velocity**: ¿Qué tan rápido nos acercamos al límite?

**Threshold de Entrada:** Se requiere un Score Combinado >= **60** (aunque internamente UnifiedVision empieza a aprobar desde 40 con 'WAIT', el Sniper busca setup perfecto).

---

## 3. Temporalidades y Jerarquía

El bot utiliza una estructura piramidal de análisis:

1.  **4H (Macro / Bias)**: Define la tendencia mayor y el "clima".
    *   *Rol*: Si 4H es alcista, los shorts en 15M tienen penalización severa.
2.  **1H (Confirmación)**: Valida la fuerza intermedia.
    *   *Rol*: Busca "Momentum Drive" (ADX > 30 sostenido).
3.  **15M (Contexto Táctico)**: Genera las señales de advertencia y contexto.
    *   *Rol*: Detecta patrones (Flags, Triángulos) y lateralización.
4.  **5M (Ejecución / Veto)**: Toma la decisión final y precisión de entrada.
    *   *Rol*: El sistema de "5M Veto" puede bloquear una entrada si detecta colapso repentino de fuerza o momentum opuesto, incluso si 15M se ve bien.

---

## 4. Módulos de Decisión Avanzada

### `brain_pattern_intelligence.py`
Detecta patrones con lógica jerárquica:
*   **Estructura de Mercado**: HH/HL (Higher High/Low). Es la base.
*   **Reversal**: Doble Techo/Suelo.
*   **Continuación**: Banderas (Flags) y Triángulos.
*   **Momentum Drive**: Patrón especial de pura fuerza (ADX > 30 + Aceleración).

### `brain_movie_engine.py` (Concepto Avanzado)
Intenta analizar la "coherencia narrativa" entre temporalidades.
*   Si 5M dice "Compra" pero 1H dice "Fuerza Muriendo", el Movie Engine recomienda rechazar.
*   Analiza fases: *Explosion Nascent* -> *Sustained* -> *Climax* -> *Fading* -> *Dying*.

---

## 5. Gestión de Riesgo Dinámica

El bot no usa un tamaño de posición fijo, sino basado en **Confianza**:
*   **Tier Alto (Score 60-100)**: 15% del capital (Setups Perfectos).
*   **Tier Medio (Score 50-60)**: 10% del capital.
*   **Tier Bajo (Score 40-50)**: 5% del capital (Exploración).

*   **Stop Loss**: Dinámico (multiplicador ATR o Estructura), típicamente ~2.0% - 2.5%.
*   **Take Profit**: Basado en R/R ratio (mínimo 2:1).

## 6. Recomendaciones para Migración/Copia Avanzada

Para crear una versión avanzada "fiel":
1.  **Preservar la Arquitectura de "Capas"**: No mezclar la lógica de indicadores (Analyzer) con la lógica de decisión (Vision/Intelligent).
2.  **Integrar el Movie Engine**: Actualmente corre en paralelo. La versión avanzada debería hacer que el `MovieEngine` sea el *único* juez de la calidad de la tendencia, reemplazando chequeos estáticos.
3.  **Refinar el "Grid Diagonal"**: Es potente para evitar compras en topes, asegurarse de que esté bien calibrado para cada activo.
4.  **Sistema de Eventos**: Migrar de un loop `while True` a un sistema basado en eventos (Websockets) para mayor velocidad de reacción ("Real-Time" real).

# main.py - Loop del videojuego
import pygame
from game.canvas import Canvas
from market.market_entity import Market
from brain.narrator import Narrator
from brain.vision import Vision
from brain.trader import Trader
def main():
    # Inicializar
    pygame.init()
    canvas = Canvas(width=1280, height=720)
    market = Market(symbol='BTC/USDT')
    narrator = Narrator()
    vision = Vision()
    trader = Trader()
    
    running = True
    clock = pygame.time.Clock()
    
    while running:
        # 1. EVENTOS (teclas, mouse)
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False
        
        # 2. UPDATE (cada frame)
        market.update()  # Obtiene nuevo precio
        
        # 3. VISION (ve la película)
        what_bot_sees = vision.observe(market)
        
        # 4. NARRADOR (explica lo que ve)
        narrator.describe(what_bot_sees)
        
        # 5. DECISION (basada en visión)
        action = vision.decide(what_bot_sees)
        
        if action == 'ENTER':
            trader.enter_trade(market.current_price)
        elif action == 'EXIT':
            trader.exit_trade()
        
        # 6. RENDER (dibujar todo)
        canvas.clear()
        canvas.draw_price_action(market.price_history)
        canvas.draw_zigzag(market.zigzag)
        canvas.draw_volume_profile(market.volume_profile)
        canvas.draw_indicators(market.adx, market.momentum)
        canvas.draw_order_lines(trader.entry, trader.tp, trader.sl)
        canvas.draw_narrator(narrator.messages)
        canvas.flip()
        
        # 7. FPS
        clock.tick(60)  # 60 FPS
    
    pygame.quit()
if __name__ == '__main__':
    main()

# market/market_entity.py
class Market:
    """
    El mercado como entidad física en un videojuego.
    
    Precio = Pelota moviéndose
    Resistencia = Pared superior
    Soporte = Pared inferior
    ADX = Velocidad de la pelota
    Momentum = Dirección de la fuerza
    """
    
    def __init__(self, symbol):
        self.symbol = symbol
        
        # Posición (precio)
        self.position = 0
        self.position_history = []  # Trail de la pelota
        
        # Física
        self.velocity = 0        # Velocidad actual
        self.acceleration = 0    # Aceleración
        self.force = 0           # Fuerza aplicada (ADX)
        self.direction = 0       # Dirección (-1, 0, +1)
        
        # Paredes
        self.resistance = 0      # Pared superior
        self.support = 0         # Pared inferior
        
        # Indicadores visuales
        self.adx = ADXVisual()
        self.momentum = MomentumVisual()
        self.zigzag = ZigZagVisual()
        self.volume_profile = VolumeProfileVisual()
    
    def update(self):
        """Actualiza física del mercado cada frame."""
        
        # Obtener nuevo precio
        new_price = self._fetch_price()
        
        # Calcular física
        old_velocity = self.velocity
        self.velocity = new_price - self.position
        self.acceleration = self.velocity - old_velocity
        
        # Actualizar posición
        self.position = new_price
        self.position_history.append(new_price)
        
        # Mantener historia (últimos 100 puntos)
        if len(self.position_history) > 100:
            self.position_history.pop(0)
        
        # Actualizar indicadores
        self.adx.update(self._fetch_adx())
        self.momentum.update(self._fetch_momentum())
        self.zigzag.update(self.position_history)
        
        # Detectar paredes
        self._update_walls()
    
    def _update_walls(self):
        """Encuentra resistencias y soportes (paredes)."""
        # Usar ZigZag para encontrar niveles
        highs = self.zigzag.get_highs()
        lows = self.zigzag.get_lows()
        
        if highs:
            self.resistance = min(h for h in highs if h > self.position)
        if lows:
            self.support = max(l for l in lows if l < self.position)
    
    def distance_to_wall(self, direction):
        """Calcula distancia a pared (runway)."""
        if direction > 0:  # BULLISH
            return self.resistance - self.position
        else:  # BEARISH
            return self.position - self.support
    
    def time_to_collision(self, direction):
        """Cuántos frames hasta chocar con pared."""
        distance = self.distance_to_wall(direction)
        if abs(self.velocity) > 0:
            return abs(distance / self.velocity)
        return float('inf')

# brain/narrator.py
class Narrator:
    """
    Narrador que explica en tiempo real lo que el bot ve.
    Como un comentarista de fútbol para trading.
    """
    
    def __init__(self):
        self.messages = []
        self.max_messages = 5
    
    def describe(self, vision_data):
        """Genera descripción de lo que el bot ve."""
        
        self.messages = []
        
        # ADX
        adx = vision_data['adx']
        if adx['trend'] == 'SUBIENDO':
            self.say(f"ADX: {adx['values']} - Fuerza EMERGENTE")
        elif adx['trend'] == 'BAJANDO':
            self.say(f"ADX: {adx['values']} - Fuerza MURIENDO")
        
        # Momentum
        mom = vision_data['momentum']
        if mom['color'] == 'GREEN' and mom['growing']:
            self.say("Momentum VERDE creciendo - Explosión posible")
        elif mom['color'] == 'RED':
            self.say("Momentum ROJO - Presión vendedora")
        
        # Precio
        price = vision_data['price']
        if price['accelerating']:
            self.say(f"Precio ACELERANDO hacia {price['direction']}")
        
        # Runway
        runway = vision_data['runway']
        if runway['frames'] < 5:
            self.say(f"ADVERTENCIA: Solo {runway['frames']} frames hasta pared")
        else:
            self.say(f"Runway despejado: {runway['frames']} frames")
        
        # Decision
        if vision_data['explosion_starting']:
            self.say(">>> EXPLOSION INICIANDO - ENTRAR <<<")
        
    def say(self, message):
        """Agrega mensaje al narrador."""
        self.messages.append(message)
        if len(self.messages) > self.max_messages:
            self.messages.pop(0)

# brain/vision.py
class Vision:
    """
    Los ojos del bot.
    Ve la película del mercado frame a frame.
    """
    
    def observe(self, market):
        """Observa el mercado y extrae patrones visuales."""
        
        # Ver película de ADX
        adx_movie = self._watch_adx(market.adx.history)
        
        # Ver película de momentum  
        momentum_movie = self._watch_momentum(market.momentum.history)
        
        # Ver película de precio
        price_movie = self._watch_price(market.position_history)
        
        # Ver espacio (runway)
        runway = self._watch_runway(market)
        
        # Determinar si hay explosión iniciando
        explosion_starting = (
            adx_movie['trend'] == 'SUBIENDO' and
            momentum_movie['growing'] and
            price_movie['accelerating'] and
            runway['frames'] > 3
        )
        
        return {
            'adx': adx_movie,
            'momentum': momentum_movie,
            'price': price_movie,
            'runway': runway,
            'explosion_starting': explosion_starting
        }
    
    def _watch_adx(self, history):
        """Ve la película del ADX."""
        if len(history) < 3:
            return {'trend': 'UNKNOWN', 'values': []}
        
        recent = history[-5:]
        
        # Contar frames subiendo vs bajando
        ups = sum(1 for i in range(len(recent)-1) if recent[i+1] > recent[i])
        downs = len(recent) - 1 - ups
        
        if ups > downs:
            trend = 'SUBIENDO'
        elif downs > ups:
            trend = 'BAJANDO'
        else:
            trend = 'LATERAL'
        
        return {
            'trend': trend,
            'values': '->'.join(f'{v:.0f}' for v in recent)
        }
    
    def _watch_momentum(self, history):
        """Ve la película del Momentum."""
        if len(history) < 3:
            return {'color': 'NEUTRAL', 'growing': False}
        
        recent = history[-5:]
        
        # Color basado en valor
        last = recent[-1]
        color = 'GREEN' if last > 0 else 'RED' if last < 0 else 'NEUTRAL'
        
        # Está creciendo?
        growing = abs(recent[-1]) > abs(recent[0])
        
        return {'color': color, 'growing': growing}
    
    def _watch_price(self, history):
        """Ve la película del precio."""
        if len(history) < 4:
            return {'accelerating': False, 'direction': 'LATERAL'}
        
        recent = history[-5:]
        
        # Velocidades
        velocities = [recent[i+1] - recent[i] for i in range(len(recent)-1)]
        
        # Aceleración = velocidad creciendo
        accelerating = abs(velocities[-1]) > abs(velocities[0])
        
        # Dirección
        total_move = recent[-1] - recent[0]
        direction = 'BULLISH' if total_move > 0 else 'BEARISH'
        
        return {'accelerating': accelerating, 'direction': direction}
    
    def _watch_runway(self, market):
        """Ve el espacio disponible."""
        direction = 1 if market.velocity > 0 else -1
        frames = market.time_to_collision(direction)
        
        return {'frames': frames}
    
    def decide(self, vision_data):
        """Toma decisión basada en lo que ve."""
        if vision_data['explosion_starting']:
            return 'ENTER'
        
        # Aquí agregar lógica de EXIT
        
        return 'HOLD'

    """
    
    def __init__(self, width=1280, height=720):
        self.width = width
        self.height = height
        self.screen = pygame.display.set_mode((width, height))
        pygame.display.set_caption("BrainTrader 2.0")
        
        # Áreas de la pantalla
        self.price_area = pygame.Rect(0, 0, width, height * 0.6)
        self.indicator_area = pygame.Rect(0, height * 0.6, width, height * 0.25)
        self.narrator_area = pygame.Rect(0, height * 0.85, width, height * 0.15)
        
        # Colores
        self.bg_color = (20, 20, 30)  # Azul oscuro
        self.price_color = (0, 150, 255)  # Azul claro
        self.zigzag_color = (255, 230, 0)  # Amarillo
        
        # Font
        self.font = pygame.font.Font(None, 24)
    
    def clear(self):
        """Limpia pantalla."""
        self.screen.fill(self.bg_color)
    
    def draw_price_action(self, history):
        """Dibuja línea de precio."""
        if len(history) < 2:
            return
        
        # Normalizar precios a pixels
        min_p = min(history)
        max_p = max(history)
        range_p = max_p - min_p if max_p != min_p else 1
        
        points = []
        for i, price in enumerate(history):
            x = self.price_area.x + (i / len(history)) * self.price_area.width
            y = self.price_area.bottom - ((price - min_p) / range_p) * self.price_area.height * 0.9
            points.append((x, y))
        
        pygame.draw.lines(self.screen, self.price_color, False, points, 2)

    def draw_order_lines(self, entry, tp, sl):
        """Dibuja líneas de Entry, TP, SL."""
        if entry:
            self._draw_horizontal_line(entry, (0, 255, 0), "ENTRY")
        if tp:
            self._draw_horizontal_line(tp, (0, 150, 255), "TP")

    def __init__(self, size=10):

    def detect_acceleration(self):
        """Ve la película: ¿acelera o desacelera?"""
        if len(self.frames) < 3:
            return None

        for i in range(len(self.frames)-1):
            v = self.frames[i+1].price - self.frames[i].price
            velocities.append(v)
