1. El Error del Momentum "Invisible" (Squeeze)
El bot está programado para ignorar el momentum si detecta que el precio está en "Squeeze" (Bandas de Bollinger dentro de Keltner). Cuando hay Squeeze, devuelve NEUTRAL y valor 0, ocultando la fuerza que se está gestando (el histograma que tú ves crecer). Esto explica por qué ves "Momentum NEUTRAL (0 velas)" aunque en el gráfico veas barras verdes.

Código Actual (
brain_calculator.py
):

python
    # 3. Squeeze Detection
    sqzOn = (lowerBB > lowerKC) & (upperBB < upperKC)
    
    if sqzOn.iloc[-1]:  # <--- AQUÍ ESTÁ EL ERROR
        return {
            'color_current': 'neutral', # Fuerza a NEUTRAL aunque el histograma sea verde
            'color_history': [],
            'consecutive_count': 0,
            'strength': 'débil',
            'value': 0.0, # Borra el valor real

Propuesta de Ajuste: Eliminar ese bloqueo para calcular el momentum SIEMPRE, y solo avisar que hay squeeze mediante el flag squeeze_active. Así el bot verá el histograma LIME creciendo incluso dentro del squeeze.

El Momentum pierde las primeras ~40 velas por el cálculo de regresión, quedándose con muy poca historia efectiva.
